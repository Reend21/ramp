# RAMP (Reend's Awesome ModPack)
> *This Modpack targeting to players play this game with minimized bugs, much bearable AI and wide-range QoL improvements. Now it's Diesel 3 compatible!*

This mod isn't just a "native but slightly better mod". It can contain mods that **modificate the game itself**. It can give you **obvious mechanical advantage** and change **AI behaviour**. It can manipulate or change **HUD elements**, **modifications**, **guns**, **graphics** and it can even **unlock locked contents**. So this mod isn't a great mod that people want a native game but without crashes and people that would play this game for a criticise.

This mod DOESNT contain mods like; Mods that adds completely new mechanic to the game, Furry and gay mods, Mods like [Restoration Mod](https://modworkshop.net/mod/428), Mods that add new musics, map, gun etc. to the game. And most importantly **cheatworkshop** mods.

I'm open to any mod suggestions. if you tell me which mods are good and which ones are useless, I'll improve the modpack. Some standolone mods may have been already included in any other mods (like vainllahud+) so if there is a situtation like this, please give a feedback.

# Installation

## Installation via BeardLib scripts (Work in progress):
Only preequest is **SuperBLT** that has a Diesel 3 Engine support.

- Install the zip via GitHub or ModWorkshop and extract it
- Drop the "placeholder" file in the autoInstallationScript folder into the mods folder
- Run the game and you're done!

## Manual Installation
- Install the zip via **ModWorkshop** and extract it
- "Drop this mods to mods folder" Drop every mod into the your mods folder.
- "Drop this mods to overrides folder" Drop every mod into the your /assests/mod_overrides folder. If its not there, just create it.
- Run the game and you're done!
